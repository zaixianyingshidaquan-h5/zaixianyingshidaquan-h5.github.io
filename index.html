观影指南

HOW TO WATCH RIGHT

找片：先定维度再搜片名

  • 类型 → 地区 → 年代 → 情绪 → 片名
  • 别直接搜“免费看 XX”，那条路通向盗链
  • 记不住片名就记导演/摄影师/配乐
  • 短片看作者，长片看节奏，剧集看人物弧
  • 公版片先查发行方，再查字幕组是否授权

避坑：这些词=版权雷区

  • “全网免费 / 破会员 / 解析接口”
  • “刚上映高清版 / 院线同步 / 抢先版”
  • “安装专用播放器 / 关杀软 / 加群拿源”
  • “资源来自网络，侵权删”不能代替授权 [5](@ref)
  • 深度链接/盗链本身就可能构成侵权 [7,13](@ref)
